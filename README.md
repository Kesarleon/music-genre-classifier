
# 🎶 Music Genre Classifier

Este proyecto entrena un modelo de clasificación de **género musical** usando un **dataset sintético y desbalanceado** de canciones.  
Incluye un **EDA básico** y la aplicación de **SMOTE** para balancear las clases minoritarias.

---

## 🚀 Contenido
- `music_classifier.ipynb` → Notebook principal con:
  - Generación del dataset sintético
  - Exploración de datos (EDA)
  - Entrenamiento del modelo de clasificación
  - Comparación con y sin SMOTE
